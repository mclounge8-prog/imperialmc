# Аналитика Imperial MC

Сюда складываем помесячные разборы: выгрузку из учёта (POS) и внешние документы — сначала банковские выписки, потом траты, если появятся.

## Как устроено

```
analytics/
  YYYY-MM/
    figures.json          # сводные цифры месяца (POS + то, что удалось аккуратно снять с выписки)
    pos-dump.json         # сырая выгрузка из системы учёта
    sber-statement-*.pdf  # выписка, если за месяц прислали
    README.md             # разбор и тейки
```

Цифры выручки, чеков, скидок, отмен и номенклатуры — из POS (закрытие чека в часовом поясе `Asia/Yekaterinburg`).

Выписка Сбера — про движение денег по расчётному счёту ИП. Это не P&L: там нет налички из кассы и аренды целиком, зато есть переводы во вклад и смешанные карточные покупки.

Рабочая разметка выводов со счёта (как сказал владелец):

- назначение **«Доход от предпринимательской деятельности»** на карту Дёмкиной — это заработок / вывод себе;
- выводы **15 или 16 числа**, даже с той же формулировкой, — чаще зарплаты сотрудникам;
- отдельные реестры Сбера («Аванс по заработной плате») — белый ФОТ.

В выписках есть персональные данные (счёт, карты, ИНН). Ветка для внутренней работы, не для публичной витрины.

## Что ещё нужно, чтобы считать прибыль

- аренда и коммуналка по точкам
- ФОТ / подряд
- закупки с разнесением по точкам (МАРР, пиво, упаковка уже видны кусками)
- налоги

Пока этого нет — рассуждаем по выручке, миксу, скидкам и дырам в операционке.

Сценарии подъёма цен 5–10% под нагрузку «налоги + эквайринг 15%»: [`menu-price-lift/`](./menu-price-lift/).
