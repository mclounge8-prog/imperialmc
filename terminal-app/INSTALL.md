# Первичная установка Imperial MC Terminal на планшет

Пошагово: один раз ставите APK вручную, дальше обновления приходят с сервера (APK или JS OTA).

## Что нужно

- Android-планшет (рекомендуется Android 10+)
- ПК с Android SDK / USB-отладкой **или** способ скопировать APK на планшет (USB-накопитель / облако)
- Доступ к бэкофису `https://imperial-mc.online`
- На планшете отдельно установлено приложение **«Драйвер ККТ АТОЛ»** (для фискализации)

## 1. Собрать первый release APK

На машине разработки:

```bash
cd terminal-app
chmod +x scripts/build-release-apk.sh scripts/build-js-ota.sh
./scripts/build-release-apk.sh 1 1.0.0
```

Файл появится в `terminal-app/dist/ImperialMcTerminal-v1-1.0.0.apk`.

> Важно: подпись APK должна быть одной и той же для всех последующих обновлений.
> Сейчас release подписан debug-keystore проекта — для зала это ок, пока вы не смените keystore.
> Если смените ключ — планшеты не смогут обновиться «поверх», нужна полная переустановка.

## 2. Опубликовать APK в бэкофисе (желательно сразу)

1. Войти в бэкофис → раздел **«Обновления»**
2. **Загрузить APK**: тот же файл, `versionCode=1`, `versionName=1.0.0`
3. Сохранить

Так манифест на сервере совпадёт с тем, что стоит на планшетах. Следующие сборки — с `versionCode` 2, 3, …

## 3. Установить на планшет (первый раз)

### Вариант A — USB + adb (удобнее)

1. На планшете: **Настройки → Для разработчиков → Отладка по USB** (включить)
2. Подключить USB к ПК
3. Выполнить:

```bash
adb devices
adb install -r terminal-app/dist/ImperialMcTerminal-v1-1.0.0.apk
```

### Вариант B — файл на планшет

1. Скопировать APK на планшет (USB-Otg / Google Drive / Telegram себе)
2. Открыть файл на планшете → **Установить**
3. Если Android спросит — разрешить установку из этого источника (Файлы / Chrome / …)

## 4. Первый запуск и привязка

1. Открыть **Imperial MC Terminal**
2. В бэкофисе → **Устройства** → сгенерировать код регистрации
3. Ввести код на планшете
4. В бэкофисе назначить устройству **заведение** и убедиться, что оно **активно**
5. Войти по PIN сотрудника

## 5. Разрешение на обновления из приложения

При первом in-app обновлении APK Android попросит разрешить установку из «Imperial MC Terminal»:

**Настройки → Специальный доступ → Установка неизвестных приложений → Imperial MC Terminal → Разрешить**

(формулировки зависят от прошивки планшета). Без этого JS OTA будет работать, а полные APK-обновления — нет.

## 6. Как обновлять дальше (без USB и без браузера)

Сборка APK/JS всё ещё на Mac (нужен Android SDK / Node). На сервер файл уходит скриптом по SSH — в бэкофис руками загружать не нужно.

```bash
export SSHPASS='пароль-от-сервера'   # если нет SSH-ключа

# Полный APK (АТОЛ / native / новая версия приложения)
cd terminal-app
./scripts/publish-apk.sh 2 1.1.0 "Что нового"

# Только JS (экраны / логика)
./scripts/publish-js-ota.sh 1 "Убрали свайпы"
```

На планшете: при старте или **Настройки → Обновления**.

Проверка манифеста: `https://imperial-mc.online/api/terminal/updates`

Раздел бэкофиса «Обновления» остаётся запасным способом (загрузка файла вручную).

### Мелкие правки UI / логики (без АТОЛ/native)

```bash
cd terminal-app
./scripts/publish-js-ota.sh 1
```

### Изменения native / АТОЛ / permissions / новая версия RN

```bash
cd terminal-app
./scripts/publish-apk.sh 2 1.1.0
```

Планшет скачает файл сам и поставит (для APK — системный установщик).

## Проверка

- Манифест: `https://imperial-mc.online/api/terminal/updates`
- Файлы: `https://imperial-mc.online/updates/...`
- На планшете: **Настройки → Обновления** — видна строка `APK x.y (code)`

## Типичные проблемы

| Симптом | Что сделать |
|---|---|
| «Установлена актуальная версия», а вы ждали апдейт | `versionCode` / JS version на сервере не больше, чем на планшете |
| APK не ставится | другой signing key или не выдано разрешение на установку |
| JS OTA не применяется | release-сборка? (в debug всегда Metro). В ZIP есть `index.android.bundle`? |
| После APK пропал JS OTA | так и задумано: новый APK несёт свой JS; при необходимости опубликуйте новый JS OTA |
